# Case Studies

Version 0.2.0 includes twelve constructed cases in [`fixtures/synthetic/cases.json`](../fixtures/synthetic/cases.json). They exercise the five assessment states and selected boundaries involving evidence timing, authority, feasibility, integrity, outcome, correction, reform, and autonomy.

The synthetic cases test internal artifact behavior. They are not operational observations and do not represent a sampled decision population.

No operational or public-case reconstruction has been accepted into version 0.2.0.

A case may enter this directory when it contains a declared decision boundary, contemporaneous records, source provenance, publication authority, redaction statement, missing-evidence register, protocol version, independent reviewer results, and limits on interpretation.

## Planned case set

The first evaluation should include three frozen agent-mediated cases:

1. a case supporting a bounded reliance and practical-control proposition;
2. a case with incomplete or conflicting evidence;
3. a case in which formal authority exists and practical intervention fails.

Synthetic or simulated cases must identify which properties are constructed and which conclusions cannot transfer to operational deployments.

## Privacy and authority

Do not publish personal data, confidential records, security-sensitive details, or institutionally restricted material without documented authority. A redacted case must identify how redaction affects the assessment.
