# v0.16.1: Repository alignment for the v0.16.0 manuscript

## Why this patch exists

The v0.16.0 release contains the rebuilt manuscript, formal event-control rule, deterministic case results, figures, and integrity audit. Several current-state repository files still described earlier versions. The citation section named v0.12.0, the figure metadata named v0.15.0 as its source release, the audit protocol linked to v0.14.0 outputs, and the Overleaf receipt described v0.15.0.

Changing those sealed files under the existing v0.16.0 tag would invalidate its published checksums. This patch corrects the live repository while preserving the v0.16.0 release as an immutable historical snapshot.

## What changed

- Corrects the reader-facing and machine-readable citation instructions.
- Identifies the v0.16.0 GitHub release as the current working-paper source.
- Preserves `10.5281/zenodo.21926005` as the DOI for the earlier v0.14.0 preprint and prevents that DOI from being assigned to v0.16.0.
- Adds a formula register for eight v0.16.0 formulas, a JSON schema, reusable LaTeX, plain-language explanations, implementation paths, and interpretation limits.
- Aligns the core figure manifest and figure register with source release v0.16.0.
- Corrects the Figure A3 description from 20 to 40 material claims and updates the current manifest language.
- Updates the Chain-of-Evidence protocol to the 40-claim v0.16.0 audit and its current attestation.
- Records the 30-page v0.16.0 XeLaTeX compilation in Overleaf and preserves the v0.15.0 receipt separately.
- Extends repository validation to check formula schema conformance, unique identifiers, source markers, implementation paths, and LaTeX identifiers.

## What did not change

The patch changes no manuscript claim, source permission, case packet, assessment state, case-level event-control result, figure data, or interpretation boundary. The v0.16.0 result remains zero passing cases, two failing cases, and one unresolved case among the three purposively selected packets.

## Citation boundary

The v0.16.0 working paper has no version-specific DOI. Cite its versioned GitHub release. The Zenodo v0.14.0 DOI remains a valid identifier for that earlier preprint. The machine-readable preferred citation in `CITATION.cff` makes this relationship explicit.
