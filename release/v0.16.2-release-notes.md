# v0.16.2: Paper workspace organization

## Problem addressed

The `paper/preprints/` directory placed the current v0.16.0 paper beside three retired v0.15.0 delivery files. A reader had to infer the latest paper from filenames and release history. This patch gives the paper workspace one explicit starting point and separates the retired package.

## Current paper

The latest research paper remains v0.16.0. Its 30-page PDF, LaTeX source, deterministic source archive, metadata, source manifest, and compile receipts remain in `paper/preprints/`.

`paper/README.md` now opens with direct links to the current PDF, review and endorsement guide, current package, LaTeX source, GitHub reader edition, and archive index. `paper/REVIEW.md` gives a reviewer or prospective arXiv endorser one current PDF, a `cs.CY` category-fit summary, a version guide, supporting evidence paths, and five focused questions for any separate substantive review. `paper/preprints/README.md` identifies the PDF in its first sentence. The historical `paper/arxiv/README.md` now directs readers to the current review guide before they share or submit a paper.

## Archived files

- `preprints-compiled-v0.15.0.pdf`
- `preprints-source-v0.15.0.zip`

The historical validator previously read the current `paper/manuscript.md` while checking v0.14.0 wording. It now reads `paper/arxiv/main.tex`, so version-specific abstract and marker checks stay attached to the package being validated.
