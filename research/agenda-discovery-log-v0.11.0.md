## Decision

The direct-query tranche produced four findings that change the work sequence without changing the three frozen topics or project question.

## Findings

### 1. Access and inspectability are separate states

The legal-research paper loaded as a 20-page publisher PDF, yet the retrieval channel supplied no readable text layer. Treating that record as screened would convert file access into a content claim. The ledger now records retrieval as complete and screening as open.

**Sequence effect:** Resolve source readability and author metadata before moving this record into the literature matrix or manuscript.

### 2. Preserved provenance can recover a source that public title search misses

Exact-title searching did not locate the legal-research paper. The frozen Semantic Scholar record preserved the AALL publisher locator, which recovered the PDF.

**Sequence effect:** For title-only records, inspect preserved index provenance before declaring a source unavailable.

### 3. A parallel information path can defeat intervention effect

The concept-residual study shows that a corrected human-readable concept may fail to change the output when an opaque residual path retains the same information. This mechanism was not explicit in the original agenda.

**Sequence effect:** Add intervention-path integrity to the literature matrix and later examine whether the practical-control protocol should ask whether another technical or organizational path can bypass the human correction. Any protocol change requires a dated amendment and cannot alter the released case assessments retroactively.

### 4. Human-performance work overlaps the Patriot case family

The Gielas abstract challenges vague loop labels, centers cognitive readiness, proposes human in the mesh, and names the Patriot system. This is closer to the paper than its inaccessible status suggested.

**Sequence effect:** Full-text review of Gielas comes before detailed manuscript comparison. The contribution remains bounded to the integrated evidence procedure.
